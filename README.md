# 내 목소리 TTS (voice-tts-maker)

내 목소리를 녹음해서 **내 목소리로 글을 읽어 주는 TTS**를 만들고, 휴대폰과 다른 곳에 적용하는 안드로이드 앱입니다.
인터넷·서버 없이 휴대폰 안에서만 동작하며, 녹음은 기기 밖으로 나가지 않습니다.

## 할 수 있는 것

| 기능 | 설명 |
|---|---|
| 녹음 제안 | ① 기본 음절 334개 ② 받침 소리 56개 ③ 숫자·시간·단위 ④ 자주 쓰는 표현 ⑤ 문장 낭독 ⑥ 내 문구 |
| 자동 녹음 | 글자를 읽고 멈추면 자동 저장 후 다음 글자로 넘어감. 너무 크거나 작은 소리는 다시 요청 |
| 바로 적용 | 녹음할 때마다 저장되고, 그때까지 녹음한 만큼 즉시 TTS에 반영 |
| 말해 보기 | 글 입력 → 내 목소리로 재생, 빠르기 조절, 빠진 소리 안내 |
| 소리 파일 | WAV 저장·공유, 기본 벨소리/알림음/알람음으로 지정 |
| 휴대폰 전체 TTS | 안드로이드 "텍스트 음성 변환" 엔진으로 등록 → 내비·읽어주기 앱이 내 목소리로 말함 |
| 목소리 팩 | 모든 녹음을 zip 하나로 백업·복원·기기 이동 |
| 학습용 데이터셋 | LJSpeech 형식 zip (GPT-SoVITS, Piper 등 AI 음성 학습 도구용) |

## 소리를 만드는 방식

1. 글을 한글 발음으로 바꿉니다 (숫자·영문 읽기, 연음·비음화·경음화 등 발음 규칙).
2. 통째로 녹음된 낱말·문장이 있으면 **그 녹음을 그대로** 씁니다 (가장 자연스러움).
3. 없으면 음절 조각(초성+모음)과 받침 조각을 파형을 맞춰 이어 붙입니다.

①+② 390개(약 15~20분)를 녹음하면 모든 한글을 읽을 수 있습니다.
이어 붙인 소리는 내 목소리이지만 또박또박 끊어 읽는 느낌이 납니다.
사람처럼 매끄러운 소리가 필요하면 ⑤ 문장 낭독을 많이 한 뒤 "학습용 데이터셋"을 내보내 AI 음성 모델을 학습시키면 됩니다.

## 빌드

```
./gradlew assembleRelease     # app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest   # 엔진·화면 테스트
```

GitHub에 올리면 Actions가 APK를 빌드해 "my-voice-tts-apk" 아티팩트로 올립니다.
`keystore/sideload.jks`는 업데이트 설치 때 녹음이 지워지지 않도록 항상 같은 서명을 쓰기 위한 개인 설치용 키입니다.
